DEVICE SAFETY

Full flash backup

Preserve original firmware before installing anything, including on a new board.

Privacy: A complete flash image can contain Wi-Fi passwords, API keys, tokens and personal settings. Keep it on your own computer. Never commit it to GitHub or share it with support.
Risk: Flashing may make a device unbootable. Recovery via ESP32 download mode is often possible, but not guaranteed. Read recovery instructions.
