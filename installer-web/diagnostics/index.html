USB connection diagnostics

Identify your USB serial adapter before installation. This tool does not read flash, transmit serial commands, erase memory, or install firmware.

Detection ≠ board verification. Browser USB metadata can identify a USB-to-serial bridge, not prove the connected chip is an ESP32, that the display is ST7789, or that flash size and partitions are compatible.

Safety and privacy

  • No automatic USB connection on page load.
  • No write, erase, reset, or serial transfer commands.
  • No firmware binary downloads, API keys, or Wi-Fi credentials.
  • All diagnostics remain in this browser tab; nothing is uploaded.
  • USB bridge VID/PID are advisory only. Hardware identification requires a later separately reviewed procedure.
