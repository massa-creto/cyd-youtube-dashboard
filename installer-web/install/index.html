REAL FLASH WRITE — FULL INSTALL NOT HARDWARE VERIFIED. Backup is optional. Without a backup, the installer must use a full three-image installation because it cannot independently verify the current partition layout. This writes the bootloader, partition table and application and may make existing data inaccessible. With a valid 4 MB backup whose partition table matches, application-only flashing is available. Never disconnect USB during a write. Read recovery instructions first.

Install firmware

Backup is not required. You can create a separate local backup using Backup Device (requires the local Python companion). The backup process is not integrated into the browser installer.
