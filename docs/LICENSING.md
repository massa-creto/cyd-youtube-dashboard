**Noncommercial is a real restriction.** A publicly visible repository under these terms is *source-available*, not OSI-approved open source. Commercial reuse requires permission from the applicable rights holders. The precise treatment of monetized creator use is not guaranteed by a simple label; request permission when in doubt.

## Publication gate

The current root `LICENSE` is a notice pointing to the official PolyForm text, **not a locally reproduced copy of the complete terms**. Before distributing firmware binaries, add a verified verbatim license copy and complete the third-party notice review. Do not modify standardized license wording to fit the project.
