RELEASE ENGINEERING

Firmware installation readiness

This page tracks the requirements for safe factory installation. The installer is deliberately disabled until every gate has been independently verified.

Factory flashing: NOT AVAILABLE · No firmware will be written from this page.

Required release gates

  • Actual compiled bootloader, partition table and application hashes
  • Verified chip family, board variant, flash capacity and flash offsets
  • Successful first boot on a spare, clean CYD
  • Documented and tested full-flash recovery on a spare device
  • First-run password, Wi-Fi and YouTube setup validation
  • Explicit maintainer approval of public binaries and license notices
