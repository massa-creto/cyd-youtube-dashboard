CYD hardware identification test

READ-ONLY TEST: This page requests USB access and uses Espressif esptool-js to identify the chip. It may reset the device and temporarily run a RAM helper. It does not read, erase or write flash. Do not proceed if the board is doing critical work. Close Arduino Serial Monitor and other USB tools first.

Use Chrome or Edge on Windows 11, served from http://localhost or HTTPS. Plug in the CYD with a data-capable USB cable.

Ready. No serial port accessed.

If identification fails, try the board's BOOT/RESET sequence documented for its hardware revision. Do not erase or flash anything.
